# Embodied Agent Alpha product freeze

Until two paid design-partner pilots are signed, changes must directly improve at least one of these outcomes:

1. Unity/Quest integration time.
2. Turn, voice, reconnect, memory, action, or permission reliability.
3. Replay coverage or audit quality.
4. The Equipment Isolation safety-instructor vertical slice.
5. macOS arm64 or Windows x64 runtime delivery.

Daily Companion and the personal Jarvis remain reference demonstrations. They may receive compatibility and critical
reliability fixes, but they do not set the SDK roadmap.
